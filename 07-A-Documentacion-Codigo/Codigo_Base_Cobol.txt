       ENVIRONMENT DIVISION.
       CONFIGURATION SECTION.
       SPECIAL-NAMES.
           DECIMAL-POINT IS COMMA.

       DATA DIVISION.
       WORKING-STORAGE SECTION.
       * Variables de entrada
       01  WS-EMPLEADO.
           05  WS-ID-EMPLEADO     PIC X(5)     VALUE "E0412".
           05  WS-NOMBRE          PIC X(20)    VALUE "JUAN PEREZ".
           05  WS-HORAS-TRAB      PIC 9(3)     VALUE 160.
           05  WS-VALOR-HORA      PIC 9(4)V99  VALUE 0015,50.

       * Variables de cálculo interno
       01  WS-VARIABLES-TRABAJO.
           05  WS-SUELDO-BRUTO    PIC 9(6)V99  VALUE ZERO.
           05  WS-DESCUENTO       PIC 9(5)V99  VALUE ZERO.
           05  WS-SUELDO-NETO     PIC 9(6)V99  VALUE ZERO.

       * Constantes simuladas
       01  WS-CONSTANTES.
           05  WS-PORC-DESC       PIC V99      VALUE ,11. * 11% de retención

       * Variables de salida con formato para impresión
       01  WS-LINEA-DETALLE.
           05  FILLER             PIC X(5)     VALUE "EMP: ".
           05  WS-OUT-ID          PIC X(5).
           05  FILLER             PIC X(3)     VALUE " - ".
           05  WS-OUT-NOMBRE      PIC X(20).
           05  FILLER             PIC X(7)     VALUE " NETO: ".
           05  WS-OUT-NETO        PIC $ZZZ.ZZ9,99.

       PROCEDURE DIVISION.
       0000-PRINCIPAL.
           PERFORM 1000-CALCULAR-SUELDO
           PERFORM 2000-MOSTRAR-RESULTADOS
           STOP RUN.

       1000-CALCULAR-SUELDO.
           * Calcular Sueldo Bruto = Horas * Valor Hora
           MULTIPLY WS-HORAS-TRAB BY WS-VALOR-HORA 
               GIVING WS-SUELDO-BRUTO
           
           * Calcular Descuento (Sueldo Bruto * 11%)
           MULTIPLY WS-SUELDO-BRUTO BY WS-PORC-DESC 
               GIVING WS-DESCUENTO
           
           * Calcular Sueldo Neto = Sueldo Bruto - Descuento
           SUBTRACT WS-DESCUENTO FROM WS-SUELDO-BRUTO 
               GIVING WS-SUELDO-NETO.

       2000-MOSTRAR-RESULTADOS.
           * Mover datos a la estructura de edición (formateo)
           MOVE WS-ID-EMPLEADO TO WS-OUT-ID
           MOVE WS-NOMBRE      TO WS-OUT-NOMBRE
           MOVE WS-SUELDO-NETO TO WS-OUT-NETO
           
           * Mostrar resultado en consola
           DISPLAY "--- PROCESAMIENTO DE LIQUIDACION ---"
           DISPLAY WS-LINEA-DETALLE
           DISPLAY "------------------------------------".
